## 🚀 核心架构升级

### 1. 纯前端安全大模型直连（无需服务器）
- 界面右上角点击 **`⚙️ API 设置`**；
- 支持填入你的 **DeepSeek / 豆包 / Kimi / OpenAI** 官方或兼容 API Key；
- **纯前端隐私安全**：密钥仅保存在访问者当前浏览器的 `localStorage` 中，绝不经过第三方服务器；
- 支持连通性与 CORS 一键测试。

### 2. 60 组垂直场景案例注册表 (`src/corpus.ts`)
- 无需配置任何 API Key 即可零门槛体验全套完整交互；
- 点击 **`📚 载入场景案例`**，一键装填高校青年、科技传媒、城市民生、生态水利、非遗国潮等 20×3 垂直场景。

## 🛠️ 本地运行与构建

```bash
# 1. 克隆代码
git clone https://github.com/william77710/ai-media-portfolio.git

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev

# 4. 生产构建打包
npm run build
```
