# AI × 融媒体内容生产作品集（Lite）

广播电视学 × AI 产品经理候选人作品集。媒眼选题策划 / 镜序分镜工作台 / 声迹采访粗剪工具 + 两个内容作品页。

## 运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

默认 Demo 模式，所有 AI 功能内置示例数据。如需真实 AI 能力，配置安全后端代理：`VITE_AI_PROXY_URL=https://your-proxy/`。前端不保存、读取或传输 API Key。

## 部署

GitHub Pages：push 到 main 分支后自动构建部署（见 `.github/workflows/deploy.yml`）。

所有未完成的真实数据、个人履历、采访材料、联系方式均标记“待补充”，不编造。
