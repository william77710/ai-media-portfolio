# MediaFlow 融媒体创作工作台 (MediaLens & ShotFlow)

面向现代内容生产的 **AI 融媒体采编与视听创作工作流系统**。聚焦从前期选题事实风控到中后期视听分镜制作的全链路闭环：

- 🌐 **在线体验网址**：[https://william77710.github.io/ai-media-portfolio/](https://william77710.github.io/ai-media-portfolio/)
- 💻 **开源代码仓库**：[https://github.com/william77710/ai-media-portfolio](https://github.com/william77710/ai-media-portfolio)

---

## 核心系统模块

### 1. 媒眼 MediaLens（选题策划与事实风控）
- **10 维全景策划矩阵**：涵盖选题价值、目标受众、报道角度、采访对象、采访提纲、已知事实、各方观点、待核实信息、事实核查清单、多平台标题方向。
- **双轨事实风控机制**：数据、政策与人物引语强制标记为待核实，生成标准化核查清单，抵御大模型幻觉。
- **20 组垂直场景案例库**：覆盖新青年职业、科技传媒、城市民生、生态环保、文化非遗等 20 个采编场景。
- **一键导出**：支持导出标准 Markdown 采编审稿单与调研大纲。

### 2. 镜序 ShotFlow（视听分镜与结构化脚本）
- **9 维专业视听分镜参数**：严格包含镜头号、景别、机位运镜、画面描述、人物动作、旁白台词、字幕花字、音效配乐、转场节奏与 AI 生图 Prompt。
- **锁定保真（Lock-Preserved）机制**：创作者锁定满意镜头后，重新生成或调整整体节奏时，锁定镜头位置与参数绝对不变，自动平滑补齐其余镜头。
- **动态时长与节奏控制**：支持目标时长（≥15s 正整数校验），自动累计分镜总时长并提供超限/不足警示。
- **双版本 Diff 对比**：可视化对比两个历史版本的镜头变动（新增、删除、修改、未变）。
- **制作级资产导出**：一键导出《现场拍摄场记单》（Markdown）与《制作级分镜表》（UTF-8 CSV）。
- **20 组专业分镜库**：涵盖人物纪实、科技评测、知识科普、文旅风光、剧情微短剧等。

## 运行模式与 API 配置

1. **默认 Demo 模式（零门槛即开即用）**：
   - 内置 40 组精编场景语料库（媒眼 20 + 镜序 20），无需输入任何 API Key 即可完整体验所有功能与导出。
2. **真实大模型直连模式（Live AI）**：
   - 支持在右上角「API 设置」中配置 DeepSeek、豆包、OpenAI 等大模型 API Key 与 Base URL；
   - 密钥仅保存在浏览器本地 `localStorage`，直接与模型接口通信，零第三方服务器中转。
