## 核心产品矩阵

### 1. 镜序 ShotFlow（第一主项目）
- **定位**：AI 短视频脚本与视听分镜工作台。
- **痛点解决**：解决创作者从灵感到视听分镜语言转化慢、AI 每次生成不稳定打乱结构的问题。
- **核心功能**：
  - 结构化分镜参数（景别、机位、画面、动作、旁白、字幕、音效、转场、生图 Prompt）。
  - **锁定保真机制**：支持单个或多个镜头锁定，重新生成时保持锁定镜头位置与内容不变，采用占位替换式精准合并。
  - **总时长校验**：动态计算并校验成片总时长（≥15秒正整数），超限状态高亮预警。
  - **双版本 Diff 对比**：支持任意历史版本比对，统计镜头新增、删除、修改、不变数量。
  - **多格式导出**：一键导出拍摄清单 Markdown 及标准制作级 CSV 表格。
  - **垂直语料库**：内置 20 组覆盖人物纪实、科技评测、知识科普、文旅风光、剧情微短剧的实战分镜场景。

### 2. 声迹 QuoteCut（第二主项目）
- **定位**：长采访检索、金句智能提炼与粗剪时间线工具。
- **痛点解决**：长视频访谈逐字稿筛选耗时、关键论点提炼主观低效。
- **核心功能**：
  - **标准 SRT 智能解析**：严格校验 `00:00:00,000 --> 00:00:00,000` 时间码格式。
  - **四分类金句挖掘**：按“事实、经历、观点、情绪表达”自动聚类与入选理由标注。
  - **时间线联动**：点击金句或片段直接同步播放器时间，双击快速加入/移出粗剪时间线。
  - **粗剪装配引擎**：支持 1 分钟短视频快剪与 3 分钟精剪自动装配，具备 Demo 智能草稿降级保障。
  - **垂直语料库**：内置 20 组新闻前线、青年职业、基层治理、生态环保等垂直场景真实长采访逐字稿。

### 3. 媒眼 MediaLens（辅助工具）
- **定位**：融媒体选题策划与事实框架助手。
- **核心功能**：
  - 10 区块系统化策划（选题价值、目标受众、报道角度、采访对象、采访提纲、已知事实、各方观点、待核实信息、事实核查清单、标题方向）。
  - 事实类信息强制高亮“待核实”标签，守住新闻专业伦理底线。
  - 内置 20 组融媒体深度选题场景。

### 4. 真实内容验证作品
- **《河流边的青春切片》**：互动微纪录片策划案（待真实采访验证占位）。
- **一份素材，三种叙事**：跨媒介（电视/短视频/播客）叙事重构对比实验。

## 两种运行模式与大模型 API 配置

1. **默认模式（零门槛即开即用）**：
   - 内置 **60 组垂直融媒体精编场景案例库**，无需输入任何 API Key 即可完整体验所有交互、生成、编辑、对比与导出功能。
2. **真实大模型直连模式（Live AI）**：
   - 点击右上角 **「API 设置」** 按钮；
   - 选择服务商（DeepSeek、豆包/火山方舟、OpenAI、Kimi/Moonshot 等兼容 OpenAI 协议接口）；
   - 输入对应 API Key 与自定义 Base URL；
   - **安全保障**：所有 API Key 仅保存在浏览器本地 `localStorage`，直接与大模型厂商通信，无任何第三方中间服务器存储，零隐私泄露风险。
